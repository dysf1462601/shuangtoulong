# 双头龙

双脑架构的自动操作手机项目，强推理模型(例如: gpt系列)负责思考规划，相当于大脑，小参数自动化模型(例如: autoglm-phone)负责控制，相当于小脑。
适合跑复杂长程任务。
项目文件整理中（待上传）

## 环境要求

- Python 3.10
- ADB

## 安装依赖

```bash
pip install -r requirements.txt
cp .env.example .env
python run_agent.py
```
